# micrack — живой процессор микрофона на VST

**micrack** берёт звук с микрофона, прогоняет его через цепочку VST2/VST3-плагинов в реальном времени и отдаёт обработанный голос дальше — в OBS, Discord, Telegram или любое другое приложение. Шумодав, компрессор, эквалайзер, де-эссер, сатурация — всё, что умеют ваши VST, работает на живом голосу с честной задержкой в десятки миллисекунд.

Написан на **Rust** (аудио-ядро) + **Tauri 2 / Svelte 5** (интерфейс). Только Windows 10/11.

## Возможности

- **Цепочка VST2 и VST3 плагинов** в реальном времени: перестановка drag-and-drop, bypass по слоту, встроенные редакторы параметров и GUI самих плагинов.
- **Два хоста: WASAPI и ASIO.** ASIO-режим работает как insert-клиент **Voicemeeter** — обработка встраивается прямо в полосу микшера.
- **Пресеты**: вся цепочка, состояния всех плагинов (каждая ручка), усиления и настройки движка — в одном JSON-файле. Пресеты переносимы между машинами (см. ниже).
- **Честная задержка**: показывается реальная цифра mic→выход (буфер + плагины + кольцевой буфер + выходной буфер), а не «размер блока».
- **Монитор**: второй выходной поток на наушники — послушать себя обработанного, не трогая основной маршрут.
- **Гейны входа и мастера**, измерители уровня с peak-hold на входе, выходе и каждом плагине.
- **Трей и автозапуск**: закрытие окна сворачивает в трей, обработка не прерывается; при старте приложения цепочка восстанавливается и запускается сама.
- **MCP-сервер**: программой можно управлять из AI-ассистентов (Claude и др.) — см. ниже.
- **Лёгкий интерфейс**: отрисовка и опрос телеметрии засыпают, когда окно свёрнуто — в фоне UI почти не ест CPU.

## Как это работает

```
Микрофон
   │  WASAPI захват  ─── или ───  ASIO insert (полоса Voicemeeter)
   ▼
micrack:  [плагин 1] → [плагин 2] → … → [плагин N]     (lock-free ring между потоками)
   │  WASAPI / ASIO вывод
   ▼
Виртуальный кабель (например, Voicemeeter) → шина → OBS / Discord / Windows-микрофон
```

Движок работает в аудио-callback без аллокаций и блокировок: захват и вывод разведены кольцевым буфером (`rtrb`), плагины обрабатываются прямо в потоке. Если micrack не запущен, Voicemeeter пропускает полосу сухой — микрофон не «умирает».

### Режим Voicemeeter Insert (рекомендуемый)

1. Установите [Voicemeeter](https://vb-audio.com/Voicemeeter/) (Banana/Potato) и включите Insert на нужной полосе.
2. В micrack выберите хост **ASIO**, устройство **Voicemeeter Insert Virtual ASIO** на вход и выход.
3. Обработанный сигнал возвращается в ту же полосу; дальше маршрутизируйте её на шины (B1/B2) как обычно.

Размер буфера в ASIO задаёт драйвер: micrack подстраивается под него. У Voicemeeter Insert буфер наследуется от главного выхода A1 — меняйте буферизацию в Voicemeeter (System Settings → Buffering), затем выключите/включите обработку в micrack.

### Без Voicemeeter: полуавтомат с VB-CABLE

Voicemeeter не обязателен. Чтобы обработанный голос дошёл до Discord/Telegram, достаточно бесплатного [VB-CABLE](https://vb-audio.com/Cable/) — виртуального кабеля из «воспроизведения» в «запись»:

```
Микрофон → micrack (WASAPI вход) → CABLE Input (выход micrack)
                                        │ виртуальный кабель
                                        ▼
                              CABLE Output ← микрофон в Discord/OBS
```

micrack помогает это настроить сам:
- если выбран хост WASAPI и виртуального кабеля нет, вверху окна появляется подсказка с кнопкой **«Скачать VB-CABLE»**;
- программа каждые 10 секунд перепроверяет устройства — как только кабель установлен, она **сама переключает вывод на CABLE Input** и показывает напоминание выбрать «CABLE Output» микрофоном в Discord;
- никаких ручных настроек маршрутизации не нужно.

Для OBS кабель можно не ставить вовсе: источник **Application Audio Capture** захватывает звук процесса micrack напрямую (учтите: при включённом мониторе захватятся оба потока — будет эхо; вывод при этом не должен идти в наушники).

## Требования

- Windows 10/11 x64
- [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (обычно уже установлен)
- VST2/VST3 плагины на ваш вкус (например: RNNoise-шумодав, ReaPlugs, T-De-Esser — все бесплатные)
- Опционально: Voicemeeter для маршрутизации и ASIO-insert режима

## Установка

Скачайте установщик со страницы [Releases](https://github.com/Vvyiloff/micrack/releases) (`micrack_*_x64-setup.exe`) и запустите — либо возьмите portable-версию (один exe, без установки).

## Сборка из исходников

Нужны: **Rust** (stable MSVC, пиннится `rust-toolchain.toml`), **Node.js 18+**, **LLVM/libclang** (для bindgen в `asio-sys`).

```powershell
cd frontend
npm install
npm run build
cd ..
cargo build --release -p micrack-desktop --features custom-protocol
```

Готовый бинарник: `target\release\micrack-desktop.exe`.

> **Два подводных камня, проверенных на практике:**
> 1. **`--features custom-protocol` обязателен** для release-сборки через cargo. Без него Tauri не вшивает фронтенд и окно пытается открыть dev-сервер `localhost:5173` (белый экран / ERR_CONNECTION_REFUSED). Альтернатива — `npm run tauri build` из `frontend/`: CLI включает фичу сам.
> 2. Если в `PATH` есть **MinGW/LLVM-MinGW clang**, bindgen в `asio-sys` берёт его sysroot и падает на `mmintrin.h`. Уберите MinGW-записи из PATH на время сборки (MSVC-таргету они не нужны).

## Использование

1. Запустите `micrack-desktop.exe`.
2. Выберите хост и устройства входа/выхода (для Voicemeeter — см. выше).
3. Добавьте папки с плагинами в сканер, соберите цепочку кнопкой «+».
4. Крутите ручки в редакторах слотов, следите за уровнями и задержкой.
5. Сохраните пресет — при следующем запуске цепочка восстановится сама.

Закрытие окна — сворачивание в трей (обработка продолжается). «Выключить обработку» — не остановка движка, а bypass всех плагинов: сухой голос продолжает идти, чтобы микрофон в Discord не пропал.

## Пресеты и перенос на другой компьютер

Пресет — это JSON: цепочка слотов (путь к DLL + уникальный ID плагина + полное состояние его ручек в base64), гейны, устройства, частота и буфер.

При загрузке на другой машине micrack ищет каждый плагин так:
1. по точному пути из пресета;
2. если пути нет — **по уникальному ID в кэше сканирования** (плагины могут лежать в других папках — главное, чтобы они были установлены и просканированы);
3. если плагина нет — слот остаётся в цепочке как «отсутствует» (в bypass), остальное загружается.

Сами DLL в пресет не входят. Устройства на новой машине нужно выбрать заново.

## MCP-сервер (управление из AI)

`micrack-desktop.exe mcp` поднимает stdio MCP-сервер: состояние движка, запуск/остановка, запись сэмплов и анализ голоса (LUFS, пики, сибилянты), добавление плагинов, установка параметров, пресеты. Позволяет ассистенту настроить звук автономно.

## Архитектура

| Каталог | Что внутри |
|---|---|
| `crates/micrack-core` | Аудио-ядро: cpal (WASAPI/ASIO), lock-free ring (`rtrb`), VST3 (`vst3-host`), VST2 (`libloading`), анализ (`realfft`, `ebur128`), пресеты, настройки |
| `apps/desktop` | Tauri 2-приложение: команды GUI, control-API (axum), MCP-сервер (rmcp), трей |
| `frontend` | Svelte 5 (runes) + Vite + Tailwind: рэк цепочки, canvas-метры, редакторы, панель устройств |
